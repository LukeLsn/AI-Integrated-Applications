## 🛠️ How to Run the Scripts
To run the JavaScript/Node.js files in this repository, ensure you are in the root directory and use the following command structure:

Running with an Environment File
Most scripts in this repo require an API key stored in a .env file. Use the built-in Node.js flag to load it:

node --env-file=.env labs/lab-01/git-cm.js

Project Files have separate instructions that can be accessed in their respective README.md files
